# Léxora Arena

Reconstrução moderna e responsiva da arena brasileira de jogos de palavras.

## Executar

Requer Node.js 18 ou superior.

```bash
npm start
```

Abra `http://localhost:8080`. Caso a porta esteja ocupada, o servidor seleciona uma das próximas nove portas e informa o endereço no terminal.

## O que está incluído

- lobby responsivo com Grand Major diário e contador em tempo real;
- Quarteto Masters, Contexto, Termo Blitz e Anagrama Rush;
- saldo local persistente e fluxo demonstrativo de inscrição/depósito;
- acessibilidade por teclado, foco visível e redução de movimento;
- servidor estático Node sem dependências externas.

> Esta versão é uma demonstração de interface. Pagamentos, autenticação, partidas competitivas e premiações reais exigem backend seguro, banco de dados e integração com um provedor de pagamentos.
